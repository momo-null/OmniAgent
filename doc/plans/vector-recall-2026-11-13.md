## 1. 背景与实测依据

### 1.1 同义漏召回实测（2026-11-13，真库转述问句，细节见 worklog）

三个转述问句（措辞与存储记忆不相交）：一个完全未命中、一个正确记忆被泛域原子
挤到 top2、一个 top1 跑偏；对照的词面直击问句全部命中。结论：**词法单通道的
失败模式 = 措辞不相交**。

### 1.2 测量尺过期（伴随问题）

本分支 S1 先把测量尺改成**自锚定**（从现库采样）——**但保留原「库内零重合」

向量有用」）。

## 2. 目标与非目标

**目标**：转述/同义问句在 L0（chat+observation）与 L1（atoms）的召回命中率有
可复现的提升；FTS 通道与全部既有不变量零退化；语音链路零感知。

**零退化的定义（三层）**：① 开关关 → 逐字节现状；② 开关开但嵌入模型未就绪 →
逐字节现状；③ 开关开且模型就绪 → **FTS 命中行的 `final` 分值与改造前逐值相等**，
向量只新增候选行。

**非目标**：不退役 FTS；不做 cross-encoder 重排（phase 2 备选）；不动
narrative/scene；不做隐性触发（「她没发起检索」问题，独立项）；不做云 API。

**范围边界**：共用 `search_l0()` 的工具（会话历史检索/见闻检索）随改造一并获得
向量候选能力，遵守同一套 scope 规则（§6），不另设开关。

## 3. 架构总览

```
查询 q ──┬─ FTS 通道（现状，取 max(3k,15) 条）──────┐
         │                                          ├─ 候选并集（RRF 名次只用于合并/去重）
         └─ 向量通道：embed(q) → 同 scope 内余弦 top-2k ─┐
                                                    ↓
   并集每行按现状公式算 final = 0.55·rel + 0.30·importance + 0.15·recency
     · 有 FTS rank → rel = bm25_rank_to_score(rank)（原值）
     · 仅向量命中 → rel = max(0, cos)
                                    ↓
   floor(0.30) / 场合·peer·圈层加权 / 轮换环 / 去冗余 —— 全部原样
```

- **RRF 不是最终排序，只做候选合并/去重**：RRF 单路 top1 ≈0.016、双路 ≈0.033，
  而 `rel∈[0,1]`、floor=0.30——把 RRF 分数当 rel 代入会被 importance/recency
  主导、大批行跌破 floor。最终分仍由既有公式给出，最终条数仍由 floor/去冗余/k 决定。
- **候选上限**：FTS 侧现状 `max(3k,15)`；向量侧 `2×top_k`（缺省 10，**不取全库**——
  全库向量会让向量臂事实上变成主排序）；并集上限同 FTS。
- **接入点**：`search_l0()` 与 `search_brain()`。narrative/scene 二期再议。
- 符号：`k=top_k`（缺省 5）=最终返回条数；向量候选 `2k`；RRF 常数 `rrf_k=60`。

## 4. 嵌入服务（`omni_core/local/embedder.py`）

- **模型**：默认 `bge-m3`（568M/1024 维/多语/8k）——CPU 推理在当前量级无感
  （查询嵌入 100-300ms 藏在秒级工具调用里）；`bge-small-zh-v1.5`（24M/~0.1GB/
  CPU 5-20ms）保留为低配选项，配置一改即切，换模型自动重嵌。
- **设备降级链（配置驱动）**：`auto | gpu | cpu`（缺省 auto）。
  `auto` = CUDA 可用且空闲显存 ≥ 阈值 → GPU(fp16)，否则 CPU；`gpu` 加载失败降 CPU；
  运行中 CUDA OOM → 自动落 CPU 并钉住；任何层不可用 → `ready()=False` → FTS-only。
  `auto` 探测**空闲**显存（需与语音引擎共存），OOM 回落 CPU 是兜底不是异常。
- **依赖隔离（硬约束）**：主 `.venv` 已有 CUDA 版 torch（语音链路在用），
  安装 sentence-transformers 可能以 CPU torch 覆盖之，打坏语音链路。embedder
  必须跑**独立 venv** 或 ONNX Runtime；主 `.venv` 一个包不动；`ready()` 探测独立环境。
- **query 侧指令**：如需检索指令前缀，只用模型配套的通用指令，不含领域词、
  不写进内核；是否使用由 A/B 实测决定。
- **进程内单例懒加载**；查询嵌入 GPU 5-15ms / CPU 100-300ms（工具调用语境下无感）。

## 5. 存储与欠账模型

- **新表**：`vectors(source, record_id, vec BLOB, model, dim, created)`，
  PK(source, record_id)。**只加幂等 DDL（CREATE TABLE IF NOT EXISTS 挂进既有
  executescript 串），严禁推进 `_SCHEMA_VERSION`**——版本不符会触发整库重建
  （DROP 全部表）；格式标识由每行 `model`/`dim` 承担，不设重复的版本键。
  验收前置：确认建表不触发重建、真库行数前后相等。
- **写入零开销**：主写路径不同步嵌；欠账 = 源表有行而 vectors 缺行。
  **欠账判定走增量水位**（meta 记进度指针），禁止每次查询全表 JOIN 对账。
- **补齐时机**：① 查询前 lazy 补（预算帽 ≤10 条或 ≤2s，超出留给心跳——爆发写入
  后最近几条短暂最终一致）；② 心跳批嵌消化积压。
- **并发与幂等**：网关/后端各一份单例，写向量一律 `INSERT OR REPLACE`。
- **孤儿行**：向量候选 JOIN 源表天然屏蔽失效行；心跳顺带清理 JOIN 不到源行的行。
- **模型换版过渡**：新 model 向量先写（不删旧行），查询按当前配置的 model 取向量
  （绝不混算两模型余弦）；新 model 欠账清零前 `ready()=False` → FTS-only。

## 6. 检索融合细节

- **scope 硬约束（最重要）**：向量候选 SQL 必须 JOIN 回源表并**复用该检索函数
  现有的全部 WHERE**（时间窗/会话与场合 ACL/进料道分道/`state='active'`）——
  禁止「先在全库 vectors 取 top 再过滤」（别的会话的内容会挤占名额甚至跨会话泄漏）。
  「不新增 WHERE」指不新增**语义过滤**，不是绕开既有 WHERE。
- **回归锁**：开关开且模型就绪时，同一批 FTS 命中行的 `final` 与改造前逐值相等；
  跨会话 scope 隔离断言（A 会话的向量候选不得出现在 B 会话结果里）。
- **成本**：query 嵌入（§4）+ lazy 补齐（预算帽）+ 余弦暴力 <20ms（scope 内万级）；
  不占主写路径。

## 7. 为什么 FTS 不退役（定稿）

1. **精确词召回**：编号/自建标记/品牌/店名——embedding 子词平滑会淹没精确 token；
2. **降级底线**：可选依赖降级链的终点；
3. **可解释性**：FTS 命中可指认原文位置（追溯纪律）；
4. 业界定论：BM25+向量混合各补对方失败模式。分词器实现可换（配置位），通道不退役。

## 10. 验收

- **S1 测量尺自锚定 + 负样本保留**：样本 ≥30 从现库采样生成（转述模板），原
  「库内零重合」负样本单列第五项断言；产出 FTS-only 基线报告（写明同义命中率
  定义与样本量）。
- **S2 embedder + 表 + 回填**：单测（设备降级链/缓存/水位/模型换版过渡/并发幂等/
  孤儿清理/独立环境探测）；验收前置=建表不触发重建、行数前后相等。
- **S3 `search_l0` 融合**：并集合并/降级/预算帽/**FTS 行 final 逐值不变**/开关关
  逐字节现状/**跨会话 scope 隔离**。
- **S4 `search_brain` 融合**：同上 + `state='active'` 不退化。
- **S5 探针进回归 + A/B 报告**：三案例 + 自锚定样本 + 负样本，对比表（满额率/
  0 召回率/平均注入字符，用于标定向量候选数）；**向量专属命中逐条人工核对**
  （记错谁说的/场合 = 净负，不计入收益）。
- **合入标准（四条全过）**：① 同义命中率相对 FTS-only 基线可复现提升且三案例
  全中（报告给样本量/基线值/幅度，不用不可证伪措辞）；② 词面断言不退化（含 FTS
  行 final 逐值相等）；③ 负样本不退化（不凭空召回、无记错人/场合）；④ 语音链路
  零感知（主写路径零新增耗时；主 .venv 零改动；开关关/未就绪逐字节现状）。

零迁移、版本键不动）✓｜只做候选生成（RRF 仅合并，final 公式原样）✓｜加权不过滤
